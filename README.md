# 📚 Learnify AI

An AI-powered study assistant designed to help students understand topics in a simple, visual and exam-friendly way.

## ✨ Features

- 🤖 AI-generated study notes
- 📖 Simple and student-friendly explanations
- 🔤 Difficult words explained with meanings
- 💡 Easy tricks and memory tips
- 📊 Diagrams and flowcharts for suitable topics
- 📝 Topic-wise learning
- 🧪 MCQ quizzes
- 🎯 5, 10 or 20 questions
- 📈 Easy, Moderate and Difficult quiz levels
- 🏆 Quiz scores and explanations
- 📜 Learning history
- 👤 Student login and personal learning data

## 🛠️ Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3.2
- SQLite
- Requests

## 🎯 Purpose

Learnify AI is designed to make studying easier by turning a student's topic into organized notes, visual explanations, examples, tricks and practice questions — all in one place.
